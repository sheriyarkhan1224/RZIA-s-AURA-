# RZIA's AURA

Supabase-connected Vite/React starter for the RZIA's AURA fashion store.

## Setup
1. Copy `.env.example` to `.env`.
2. Put your Supabase project URL in `VITE_SUPABASE_URL`.
3. Put your Supabase Publishable key in `VITE_SUPABASE_ANON_KEY`.
4. `npm install`
5. `npm run dev`
6. `npm run build`

Do NOT put a Supabase secret/service-role key in the frontend.
